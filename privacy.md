# Privacy Policy for report gsc

Last updated: 25 October 2026

report gsc is a personal tool used by a single person, its author. It is not available to the public.

## What data the app accesses

With the author's explicit consent, the app reads Google Search Console data (search performance, indexing status and sitemap status) of sites the author owns. For this it uses the Search Console API scope https://www.googleapis.com/auth/webmasters.

## How data is used and stored

The data is used only to build SEO reports for the author. It is stored on the author's own computer. The OAuth token is stored locally on the author's device.

## Sharing

The app does not sell, share or transfer Google user data to any third party, and does not use it for advertising.

## Revoking access

Access can be revoked at any time at https://myaccount.google.com/permissions
